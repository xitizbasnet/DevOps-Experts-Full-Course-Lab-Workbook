# How to Use This Workbook

Each session is broken into **numbered labs**. Every lab contains the following sections:

### 🎯 Objective

Describes **what you will achieve** by completing the lab.

### 📝 Step-by-Step Instructions

Provides detailed instructions for completing the lab, including:

* AWS Console procedures
* CLI commands
* Required configuration steps

### 🟢 Task Set 1 — Guided

Follow along with the provided prompts and instructions.

> **Purpose:** Build familiarity with the tools, commands, and workflow before attempting tasks independently.

### 🟡 Task Set 2 — Practice

Try the task yourself using the provided hints.

> **Purpose:** Reinforce the concepts introduced during the guided exercise and increase hands-on confidence.

### 🔴 Task Set 3 — Challenge

Solve a **real-world scenario independently**.

> **Purpose:** Apply the skills you have developed to a practical DevOps scenario with minimal guidance.

---

## 📝 Note

> **Prerequisites:** AWS Free Tier account (**ap-south-1**), Docker Desktop or Linux EC2, GitHub account, basic terminal comfort.

Before starting the labs, make sure you have access to all required accounts, platforms, and tools.

### Prerequisites Checklist

* [ ] AWS Free Tier account
* [ ] AWS Region: `ap-south-1`
* [ ] Docker Desktop **or** Linux EC2
* [ ] GitHub account
* [ ] Basic terminal comfort

---

## 📌 Recommended Learning Path

**Complete sessions in order.**

The workbook is designed as a progressive learning path, so completing the sessions sequentially will help ensure that concepts and practical skills introduced in earlier sessions are available for later labs and challenges.
